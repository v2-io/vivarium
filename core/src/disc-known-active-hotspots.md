# Known active hotspots (in the code, not on the world)

A maintained short list of the code regions under active truth-work *right now* — because measured claims decay fastest exactly where the kernel is molten, and a concurrent mind citing a number needs to know whether its ground is frozen or in flight.

## Formal Expression

1. **What a hotspot is.** A code region (kernel, generator, metric function) currently being reworked or recently re-keyed, such that emergent-statistic claims measured against it are **era-volatile**: still honest for their measured era, unverified for the present one. A hotspot is about *our activity*, not the world's — the name deliberately contrasts with anything geographic.
2. **The rule the list serves.** Before quoting a measured number, check whether its ground is hot; if it is, the quote carries its era or gets re-measured ( `DECISIONS[kernel-era-keys-and-the-probe-registry]` is the mechanization program). Before briefing an agent into a hot region, say it is hot and who else is in it — the same-hour cross-brief rule made standing.
3. **Name the object, not the family.** Two live seam families exist and one word covers both: the **tile seam** (same-level halo/base-level/flux — #form-same-level-halo-exchange ) and the **panel seam** (the cube-chart boundary — #obs-the-two-point-defect-lives-on-the-panel-seam ). "The seam work," unqualified, is how the next false attribution starts; hotspot rows and briefs name which.
4. **The list (refresh at every kernel-touching land, like the census; entries carry their commit era):**
   - **`water.rs` — wave LANDED, still warm** (`77b1f5a` implicit friction: steady Fr 2.0000 flat, dt-dependence gone; `de4c6c4` Jarrett demoted to bed-drop static + $\theta$ relabel): the pre-fix era's roll-wave numbers (§5/§8/§9 of the strand's note) and the grid-divergence sweep are **owed re-runs before quoting** — friction changed every base state they were measured on. 5. **Cold, and load-bearing as such:** the store/key machinery, the isostasy column and cooling chain, the stage-chain instrument — claims grounded there are not era-volatile this week.
