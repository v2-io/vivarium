## Discussion

The 2026-07-30 rank thrash (mixed-tier → weak predicates → regula → status-exists-so-convict-one-promise) is itself evidence: **run the instrument before inventing the missing one.** Status already is the conformance report; what it does not do is *gate*. The molten-code half remains useful when digests move this fast — but FE(6) is supporting, not the identity of the page. When the probe registry makes era drift mechanical, FE(6) should thin or retire; FE(5) stays as long as concurrent minds need a dated leverage argument.
