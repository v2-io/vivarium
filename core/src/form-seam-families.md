# "Seam" names several objects; each family has its own defect and repair

The English word *seam* covers independent coupling surfaces that share only "the sphere is real at joins." Merging them in briefs, rankings, or repairs is how the wrong instrument gets aimed at the right symptom. This segment is the **family table**: name the object, cite its claim home, refuse synonymy.

## Formal Expression

1. **One word is not one law.** #form-seam-flux-exchange states the *discipline* that binds every seam (exchange fluxes or declared sufficient statistics, not raw foreign state; one algebra on space × time). It does **not** say every seam is the same *interface*. FE(8) there already splits same-level tile vs hanging-node grain. Production and measurement have named more. A brief that says "fix the seam" without naming the family is under-specified.

2. **The live families (2026-07-29).** Each row is a distinct object. Related as sphere geometry or store identity; **different repairs.**

   | Family (headword — LEXICON §9) | Interface | Typical defect | Repair / claim home | Not this |
   | --- | --- | --- | --- | --- |
   | **Abutment** (same-level tile) | Matching cells, one nomos, one level | Invented base level; starved inflow; tiles grade to perimeter | Datum: Jacobi halo at $(d,\sigma,\rho)$ — #form-same-level-halo-exchange (local bed shipped; sill-graph library landed, production wire open); flux half still open | Not a refinement boundary; not a panel edge |
   | **Refinement boundary** (grain / hanging node) | Coarse face meets $2^k$ fine sub-faces | Double-counted flux; refluxing | Single-valued face flux register — #form-face-flux-register | Not an abutment halo of raw heights; a *build*-seam, never drawn by present views |
   | **Panel edge** (cube panel) | Conforming same-level cube-chart boundary | Two-point flux $O(1/h)$ on the seam ring (~99.5% of measured $L^2$) | Scheme change / panel-aware operator — #obs-the-two-point-defect-lives-on-the-panel-seam | Not fixed by tile exchange or true bulk metrics alone |

3. **Implicit is the failure mode.** A family becomes dangerous when it is *in force* but *unnamed*: the edge-sink tile contract before `EdgeContract`; the chart-edge clamp before it was written as production policy; the plain/halo dual key before prefer-halo. #form-declared-boundary-contract is the declaration column for *domain* edges; this segment is the map that stops domain edges, panel operators, and store identity from sharing one TODO line.

4. **Propagation rule.** When a new defect is found at a join: (a) name which family it is (or argue for a new row here); (b) put the conviction next to the kernel or scheme that owns it; (c) do not cite a repair from another row without showing the interface matches. Hotspot rankings ( #disc-known-active-hotspots ) say which family a rank row addresses.

5. **Out of bounds.** Collapsing FE(2)'s table into "seams are hard"; treating prefer-halo as a physics claim (it is a store-identity rule); treating the chart-edge clamp as the principled cube-edge law (it is a declared deficiency until resampling ships).

## Epistemic Status

**Max attainable: exact** for the *distinctness* of the interfaces (checkable against the cited segments and against code paths that implement different policies). **Currently `robust-qualitative`:** the table is a present-tense map of live claim homes after Jacobi adoption (`1b028c3` era); it is not a theorem that these five exhaust all future joins. Stage `draft`.

## Discussion

The 2026-07-29 adoption of same-level Jacobi exchange did not invent the chart-edge or cohort families — it made them *load-bearing*. Interior-to-face exchange was measured first ( #obs-exchange-repairs-the-seam-and-overlap-does-not ); production then runs exchange on whole faces, so every face-perimeter tile asks for a multi-cell halo off the chart. Naming that ask is what this table is for.
